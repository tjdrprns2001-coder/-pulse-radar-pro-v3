# Forex Book Lab

Clean-room project created from zero. Existing PulseRadar apps and production services are intentionally untouched.

## v0.1 skeleton
- Independent Next.js App Router + TypeScript project
- Static export for isolated deployment
- Shared responsive shell
- Empty routes: Home / Book / Chart Lab / Scanner
- No trading logic yet
- No PDF-derived content yet
- No dependency on the existing PulseRadar codebase

## Build
```bash
npm install
npm run build
```

Static output: `out/`
