# 근거·반증 레이더 v1 (2026-10-06)

기존 ChartBro 분석·스캐너에 설명 계약을 추가한다. 온체인 라벨, 신규 데이터베이스, 자동 매매, 상시 알림은 이 변경에 포함되지 않는다.

## 공통 계약

`analysis.assessment`는 서버와 브라우저가 동일한 `lib/chartbro/assessment.js`로 계산한다. 원본 규칙은 독립 연구 제안이며 강사 고유 규칙 또는 검증된 예측 모델이 아니다.

- `bullish`, `contradictions`, `unknown`: 코드·설명·값·참조 ID·시각·거래소·시간봉.
- `score`: 한 시간봉의 롱 조건 강도. 매수 확률이나 검증된 승률이 아니다.
- `confidence`: 가격·파생 데이터 품질 A–D. 온체인 검증은 포함하지 않는다.
- `eligible_for_confirmation`: 확정봉, 신선도, 구조 준비, 누락 봉, 현재 봉의 롱 트리거를 검사한다. 점수로 무효화를 덮지 않는다.

| 점수 축 | 연구 조건 | 최대 |
|---|---|---:|
| 구조 | UP 25, RANGE 10, DOWN 0, 미준비 null | 25 |
| 거래량 | 확정봉 RVOL ≥1.5 | 25 |
| 압축 | 이평 압축 폭 ≤5% | 25 |
| 실행 | 마지막 확정봉의 롱 TRIGGER_CONFIRMED | 25 |

구조·RVOL·압축 중 입력이 없으면 총점은 null이다. 알려진 조건 미충족과 입력 미확보를 구분한다. 가중치는 최적화하지 않은 표시 프리셋이며 Astra A/B/C 조건을 변경하지 않는다. 스캔 표 점수는 4H 기준(없으면 첫 성공 시간봉)이고 전체 시간봉 확인과 별개다.

등급 D: 가격 지연·누락. C: 필수 특징 또는 OI·테이커·펀딩 미확보. A: 위 입력과 tick 검증 완료. B: 입력 완료이나 tick 검증 미완료. 등급은 성과·전략 신뢰도를 의미하지 않는다.

## 후보 관찰과 가상 결과

후보 ID에 거래소·시장·종목·시간봉·엔진·설정·셋업 ID를 포함한다. 데이터 버전은 관찰 기록에 보존하므로 새 캔들 다운로드마다 후보가 복제되지 않는다. 관찰은 append-only이며 당시 snapshot을 수정하지 않는다.

`GET /api/index?route=chartbro&action=candidate-history&id=<analysis_id>`는 해당 분석 시각 이하, 같은 instrument·시간봉·엔진·설정의 관찰과 결과만 반환한다. UI는 연속된 동일 상태를 접어 단계 변경을 보여준다.

가상 결과는 첫 실행 확인 봉을 실제 snapshot으로 확보했을 때만 평가한다. 이미 지난 ACTIVE_RESEARCH를 처음 발견한 경우 최신 목표로 과거 체결을 소급 생성하지 않는다. 당시 목표 후보 중 방향에 맞는 가장 가까운 목표를 고정하며 다음 봉 시가부터 평가한다. 24/72시간 horizon, 연속 확정봉, 수수료·동일 봉 목표/손절 모호성 검사를 포함한다. 같은 후보·horizon·비용 정책은 한 번만 저장한다.

비용 정책 cost-v1: 편도 수수료 0.04%, 슬리피지·펀딩 0 가정. 실제 시장 비용이 아니며 실거래 순수익·OOS 성과로 표시하지 않는다. 분석 재조회 또는 기존 scan worker 계산 시 평가한다. 별도의 상시 성과 수집기를 만들지 않는다.

## 운영 한계

기존 Journal/PostgreSQL 저장 어댑터를 재사용한다. ephemeral 환경은 서버 재시작 시 기록이 사라지고 화면에도 이를 표시한다. 영속 DB와 장기 실행 수집기는 별도 운영 연결이 필요하다. TradingView 이미지로 OHLC·OI를 대체하거나 미확보 온체인 수치를 추정하지 않는다.
