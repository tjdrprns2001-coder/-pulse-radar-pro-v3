# Simple Trading Book 한글 구현 규격

## 출처 범위
- 심리/FOMO: 책 p.6~9
- 캔들 패턴: p.13~25
- 전략 1~7: p.28~34
- 차트 패턴 본문: p.36~56
- 인쇄용 추가 패턴: p.57~64

## 구현 원칙
책의 명칭, 방향성, 넥라인/돌파/리테스트/확인 흐름은 그대로 보존한다. 다만 책에는 대부분 정량 임계값이 없으므로 자동 탐지에 필요한 ATR 허용오차, 스윙 창, 거래량 배수, 패턴 유사도는 PulseRadar의 **근사 자동 판별**로 명시한다. 패턴 점수는 승률이 아니라 형태·확인조건의 충족 정도다.

## 캔들
망치형, 모닝스타, 상승 장악형, 적삼병, 교수형, 유성형, 하락 장악형, 이브닝스타, 흑삼병, 도지, 스피닝 탑.

## 전략 1~7
1. 반복 저항 돌파 후 확인
2. 대칭 수렴 돌파 → 리테스트 → 상승 확인봉
3. 하락 이탈 → 이전 저점 → 리테스트
4. 하락 추세 수렴 완성 후 이탈
5. 베어 플래그 넥라인 이탈
6. 수평 박스 돌파 → 리테스트 → 상승 확인
7. 불 플래그에서 넥라인만이 아니라 이전 고점 돌파까지 확인

## 차트 패턴
더블탑/바텀, 트리플탑/바텀, 헤드앤숄더/역헤드앤숄더, 하락/상승 쐐기, 상승/하락 직사각형, 상승/하락 페넌트, 상승/하락 플래그, 라운딩 바텀/탑, 컵앤핸들/역 컵앤핸들, 상승/하락 배트, 상승/하락 AB=CD, 상승/하락 쓰리 드라이브, 상승/하락 확장 삼각형, 상승/하락 다이아몬드, 지지/저항 레벨.

## 상태 머신
FORMING → READY → BREAKOUT → RETEST → CONFIRMED → ACTIVE → FAILED

한글 UI에서는 각각 형성중 / 완성 대기 / 돌파 / 리테스트 / 확인 완료 / 진행중 / 무효화로 표시한다.

## 심리/FOMO
책 p.6~9의 내용을 토대로 조사 여부, 신뢰 가능한 출처, 모든 거래에서 이기려는 충동, 사전 전략/체크리스트, 시장 순환성 인식을 체크리스트로 노출한다. 자동 FOMO 경고 수치는 책의 공식 규칙이 아니라 추격 구간을 표시하기 위한 PulseRadar 근사 로직이다.
