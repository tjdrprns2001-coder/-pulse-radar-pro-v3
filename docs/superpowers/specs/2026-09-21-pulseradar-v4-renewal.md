# PulseRadar V4 Renewal

## 목표
기능을 삭제하지 않고 사용자-facing 정보구조를 단순화한다. 중복된 연구 페이지는 고급 도구로 후퇴시키고, 모바일에서 핵심 흐름을 홈 → 스캔 → 분석 → 정보 → AI의 다섯 축으로 고정한다.

## 핵심 정보구조
- 홈: 유니버스 범위 및 핵심 작업 진입
- 스캔: 자동 전체스캔, 내 연구 스캔, 확장 시장 탐색, LIVE RADAR
- 분석: 종합 분석, 통합 차트, MTF, 스마트머니/패턴
- 정보: 코인 정보·일정·뉴스
- AI: Pulse AI 브리핑
- 검증/운영은 사이드바의 고급 메뉴로 유지

## 유니버스 표준
- 코어 유니버스: Binance USDT 무기한 선물 전체. 자동 전체스캔/내 연구 스캔/정밀 분석의 공통 기준.
- 확장 유니버스: Binance 현물 + Binance/Bybit/OKX/Gate/Bitget/MEXC/KuCoin/Hyperliquid 선물을 기초자산 기준으로 중복 제거.
- DEX 확장 감시: 페어/토큰 단위로 LIVE RADAR에서 별도 집계. 코어/확장 코인 수에 직접 합산하지 않음.

## 모바일 원칙
- 글로벌 상단바는 2행 구조.
- 하단 핵심 메뉴는 정확히 5개.
- 모든 핵심 페이지에 공통 overflow/word-wrap/safe-area 보정 적용.
- 자동스캔과 연구스캔의 긴 보조근거는 접기/펼치기.
- 코인 정보 화면은 일정 → 뉴스 → 선물 → 개요 순으로 우선 배치하며 상단 고정 바로가기 제공.
- 모바일 확장 시장 표는 불필요한 열을 숨겨 가로 스크롤을 최소화.

## 회귀 방지
scripts/verify-v4-renewal.js에서 핵심 IA, 유니버스 metadata, 500개 전체 스캔 한도, 모바일 공통 CSS, 일정/뉴스 우선순위, 서울 Vercel region을 검증한다.
