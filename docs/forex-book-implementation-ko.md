## 소스 범위

현재 업로드된 `All you should know about Forex-201-406.pdf`는 실제 PDF 150쪽이며, 인쇄 페이지 기준 **201~350**까지만 포함한다. 파일명에 적힌 351~406은 현재 소스에서 확인할 수 없으므로 구현 완료로 표시하지 않는다.

- p.201~204: 시그널 서비스, 제공자 선택, 지속 학습, 웨비나/온라인 강좌, 데모계좌

- p.247~268: 규제·윤리·사기 예방·시장조작 경고·기술/컴플라이언스
- p.269~285: 레버리지·마진과 위험
- p.286~318: 트레이딩 플랜, 자본 보존, 포지션 사이징, 스타일/타임프레임, 거래일지/사후검토

- p.336~350: RSI, SMA/EMA, MACD, Bollinger Bands, Stochastic, Fibonacci, Support/Resistance, Ichimoku와 함께 페이지에서 목록으로 언급된 Pivot, ATR, Parabolic SAR, Aroon 계산

## 자동화 원칙

책이 숫자 임계값이나 수식을 명시하지 않는 부분은 **책의 개념을 보존한 자동화 근사**로 표시한다. 표준 지표 수식은 공개 표준 공식을 사용하며, 책 자체에서 상세 수식을 제공했다고 표시하지 않는다. 캔들/지표/기존 SMC·ICT를 합친 점수는 **승률이 아니라 근거 완성도**다.
