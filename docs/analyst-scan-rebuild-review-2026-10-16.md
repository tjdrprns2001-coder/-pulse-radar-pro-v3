이 문서는 **전문가 검토 역할 및 작업 분장**을 정의한다. 이 문서만으로 독립적인 LLM 에이전트나 24시간 AI 작업자가 실행되는 것은 아니다. GitHub Actions는 반복 테스트만 자동 수행한다.

## 운영 원칙 (최고 관리자 검토)
1. 각 기능은 **발견(애널리스트) → 구현(개발) → 반례 작성(레드팀) → 전진검증(퀀트) → 최종 릴리스 심사(책임 검토)** 5단계를 통과한다.
2. 관리자도 구현 직후 승인 금지. 실패 사례·데이터 출처·역할 충돌·수치적 안정성에 대한 재검토를 요구하고, 증거가 불충분하면 재작업으로 회송한다.
3. 점수가 높아도 신선도/OI/시계열 연속성/검증된 손절의 필수 근거가 없으면 `READY` 또는 `LIVE`로 승격하지 않는다.
4. 미래 누출과 소급 보정 금지: 닫힌 봉, as-of 타임스탬프, 확정 당시 알 수 있던 소스만 사용. 보정 데이터는 별도 기록.
5. OOS는 워크포워드·purged/embargoed 분리, 비용(수수료·펀딩·슬리피지), 미관측 구간, 중복 샘플을 명시하고 성과표에서 미관측을 승리/패배로 계산하지 않는다.
6. main/배포는 검증 완료 후. CI, 실제 경로, Render 헬스·배포 버전·로그의 확인 결과를 별도로 기록한다.

## 2026-10-16 첫 번째 교차검토 결과

### P0 — 패치 작성 / 테스트 대기
- `strategy-pattern-engine.js`: `Number(null)===0`에 의한 미관측 taker/OI 사용. 공백·null·boolean도 제외, 테이커 미관측 상태는 승격 차단.
- `book-manual-engine.js`: 종전 4H 우선 위험계획이 실제 1H 진입 트리거와 섞일 수 있음. **선택 진입 TF 기준으로만** 가격/무효화/피보나치 목표 계산. 출처 TF와 시점 명시.
- `entry-confirmation-engine.js`: 진입 TF와 위험계획 TF 불일치를 무시하면 안 됨. 불일치 또는 TF 출처 없는 계획을 제외.
- `preignition-resolver.js`: 목표 시각보다 오래 뒤의 첫 가격으로 OOS 정산 가능. 첫 1분봉의 시각 차이 한정, 미래 봉 불허.
- `sampling-v3-outcome-resolver.js`: 중간 봉 미관측·종료 후 미확정 봉을 사용하면 성공/기간 종료 판정 오염. 최초~barrier 경로 연속성, no-trigger 전체 기간 커버리지, 확정 1m candle 필수.

### P1 — 아직 구현/완전 검증되지 않은 범위
- 불 플래그의 **이전 고점 이전 위치 조건**, 패턴 인식 후 실패·폐기 시점, 유효한 조정과 단순 횡보 구별.
- Bat 0.886 XA 등 고전 하모닉 비율의 tolerances, XABCD의 피벗 시점/중복, PRZ 리테스트; 단독 매수 근거로 승격 금지.
- 망치형 다음 봉 확인(거래량·고점 회복·하락추세 위치와 반례), 구름대 Senkou shift/미래 데이터 가시화 검증.
- OI 관측 시각·데이터 품질과 24H/4H/60m 순서 일치; 긴 결측의 last-good 허용 범위와 UI 레이블.
- 단테 112/224/448, 기간대칭, Wyckoff phase, VWAP·Volume Profile, 볼린저/켈트너, Elliott 등을 **선언만 존재 / 증거용 / 순위 반영 / 실시간 사용** 등 상태로 구분하는 레지스트리 매핑.
- 전체 거래소/선물 상장 가능성 및 거래소별 가격 시작점 검증; 중복 심볼과 거래정지·상장폐지 차단.

## 의사결정 규칙 (회의록 형식)
- **데이터 연구원:** 누락 수치를 0으로 바꾸면 수급 우위 오탐. 수정 동의.
- **차트 연구원:** 트리거가 1H면 같은 시점의 1H price/stop/target을 기본으로, 4H는 상위 저항·맥락에만 사용. 수정 동의.
- **OOS 연구원:** 중간 데이터가 끊긴 시점 뒤의 barrier hit는 검증 성공으로 사용 금지. 수정 동의.
- **레드팀:** 정상 사례뿐 아니라 null·공백·다른 가격대의 TF·빈 1분 구간·아직 닫히지 않은 봉으로 반례 작성 요청.
- **총괄:** 구현 브랜치 작성은 허용, **전체 CI/실제 실행/운영 검증 전에는 main 병합 및 배포 보류**.
