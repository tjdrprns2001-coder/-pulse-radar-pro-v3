# 밥그릇 조건 대량 비교 — 연구 스냅샷 2026-10-10

## 목적 및 범위

이 문서는 vectorbt의 파라미터 시나리오 비교와 Qlib의 시계열 검증 원칙을 참조한 **자체 Node.js 연구 코드**의 현재 상태를 기록한다. 원본 Python vectorbt/Qlib을 설치하거나 직접 실행한 결과는 아니다. 실매매/자동주문/투자 추천이 아니다.

코드:
- `lib/research-backtest-v2/bowl-parameter-grid.js`: 고정 8개 조합과 신뢰구간 기반 검증구간 점수. 미충족 시 테스트 잠금.
- `lib/research-backtest-v2/bowl-walk-forward.js`: 공통 UTC 캘린더 훈련·검증·최종평가 분할 + 7일 purge와 허용 분할 제한.
- `scripts/run-bowl-parameter-grid.js`: 실시간 기준 Binance USDT 무기한 직접 OHLCV만 연구. 일부 종목 누락·대체소스면 전체 선택 취소.
- `scripts/verify-bowl-parameter-grid.js`: 테스트 구간 무단 읽기 차단, 소스·그리드 검증, 날짜 경계 확인.
- `scripts/verify-bowl-parameter-grid-cli.js`: 거래소 소스 확인 및 부분 표본 탐지.
- `npm run test:bowl-parameter-grid`: GitHub Actions 자동 검증.

검증 규칙은 **전 종목에 같은 UTC 날짜 경계**를 적용하고, 학습/검증을 사용해 모델을 선택한 다음, 조건을 충족한 단일 조합에서만 최종 테스트를 연다. 성공률은 미래 봉 고가가 임계값을 터치했는지 관찰한 값이며 실현 손익이 아니다.

## 주요 한계

- 8종목은 전시장 및 상장폐지 종목의 표본이 아니다(생존·선택 편향).
- 탐지 신호는 같은 가격 추세/시장 날짜에 연관될 수 있다. 종목 수 = 독립 사건 수가 아니다.
- Python vectorbt, Qlib 원본 엔진의 재현 결과는 아니며, 방법론에서 채택한 분할·그리드 구성 요소만 자체 구현했다.
- 단순 임계값 고가 도달 검증은 체결 수수료, 슬리피지, 펀딩, 청산 위험을 반영한 포트폴리오 백테스트가 아니다.
- 마지막 참조 시점 이후 재실행하면 입력 원시봉, 커트오프, 후보 결과가 달라질 수 있다. 같은 결과의 재현을 위해 원본 시계열 스냅샷 고정이 필요하다.
