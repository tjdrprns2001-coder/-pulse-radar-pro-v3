# 트레이더 스캔 v1

2026-09-26. 기존 자동스캔과 별도로, 사용자가 조건 설계를 위임한 롱 전용 연구 스캐너.

## 진입 경로와 데이터

- 메뉴: SCAN → 트레이더 스캔. 직접 경로 `/trader-scan.html`.
- API: 기존 `/api/coin-scan`에 `trader-summary`, `trader-light&symbols=...`, `trader-deep&symbol=...` 모드 추가.
- Binance USDT 무기한 선물 TRADING 목록과 원자료만 사용. 현물 대체와 다른 거래소 대체 없음.
- 전체 시세 필터 후 거래대금 상위 24개와 10분 단위 순환 24개를 1H/4H 예비검사. 구조·이평 거리·압축·OBV로 순위를 매겨 최대 18개를 정밀검사. 실제 검사 수를 표시.
- 주봉은 확정봉 최소 26개로 SMA20/EMA20 방향을 확인. 나머지 1D·4H·1H·15m·5m은 최소 125개. 최근 봉의 시각 및 간격도 검사. SMA 5/10/20/60/120, EMA20, ATR14, Wilder RSI14, MACD선 변화, 최근 20봉 OBV 방향 표시.

## 확인 조건과 차단 조건

모든 조건이 맞아야 `CONFIRMED`다. 점수로 필수 조건을 우회하지 않는다.

1. BTC·ETH 4H가 모두 상승: 종가 > SMA60, SMA20 > SMA60, EMA20 비하락. 둘 모두 하락이거나 하나가 직전 4H -3% 이하면 위험회피, 혼조면 진입 확인 보류.
2. 종목 일봉·4H 상승, 주봉 하락 아님.
3. 1H 추세 눌림 회복, 돌파 후 최대 6봉 안 리테스트, 직전 20봉 저점 스윕·회복 중 하나.
4. 15m 종가가 직전 12봉 고가를 돌파 + 직전 20봉 평균 대비 거래량 1.5배 이상 + 5m 종가 EMA20 위.
5. 실제 OI 수량 원자료의 4H 증가율 >1%. 최근 종료한 15분 taker 3구간 중 2개 >1.2 및 평균 >1.2. 중립·누락은 통과하지 않음.
6. 24H 거래대금 ≥1천만 USDT, 변동 ±8% 이내, 스프레드 ≤10bp, 8H 환산 펀딩 ≤+0.05%, 1H EMA20 이격 ≤1.5 ATR.
7. 최근 1H 5봉 저점 -0.2 ATR을 무효화 가격으로 사용. 그 위에서 가장 가까운 **양옆 두 봉으로 확정된 4H 피벗 고가**를 목표 저항으로 사용. 손절 거리 0~6%, 비용 반영 손익비 ≥2. 저항이 없으면 목표를 생성하지 않음.

비용 가정은 편도 수수료 5bp + 슬리피지 5bp. 순손익비는 `(목표-진입-왕복비용)/(진입-무효화+왕복비용)`. 계정별 수수료나 보유기간 펀딩을 반영한 실제 체결 계산은 아니다.

`getFundingInfoMap({strict:true})`에서 성공적으로 누락된 심볼만 Binance 기본 8H 주기를 적용한다. API 실패, 잘못된 명시 주기 및 펀딩 값 누락은 데이터 부족으로 처리한다. 기존 호출은 기존의 빈 Map fallback을 유지한다.

## 상태·화면

- `CONFIRMED` 진입 확인: 모든 필수 조건 충족. 주문을 실행하지 않는다.
- `ARMED` 진입 대기: 추세와 구조가 형성됐으나 진입·수급 조건 대기.
- `WATCH` 관찰: 아직 구조가 형성되지 않음. 압축도 여기 포함.
- `EXCLUDED` 제외: 명시적 위험 차단. 해당 원인 표시.
- `DATA_GAP` 데이터 부족: 필요한 원자료가 누락·지연. 위험 차단과 동시 발생하면 제외를 우선 표시하되 누락 사유도 보존.

스코어 100점은 추세25 + 구조25(압축 관찰10) + 수급20 + 진입15 + 손익비15의 **조건 충족도**다. 승률이 아니다. 조회 후 2분 지난 진입 확인 카드는 재확인 대상으로 표시한다. 최근 세션 복원은 1시간까지만 가능.

10분/30분 자동 갱신은 화면이 열린 동안 작동한다. 숨김 상태에서는 다음 자동 시작을 멈추며, 이미 시작한 조회는 완료할 수 있다. 페이지를 떠나거나 중지하면 브라우저 요청을 취소한다. 서버의 시작된 요청 취소나 영구 예약을 보장하지 않는다.

## 검증과 한계

- `npm run test:trader-scan`: 완성/미완성 봉, 세 가지 구조, 누락·지연 OI/체결/펀딩/호가, 시장 위험, 과진행, 근접 저항, 기본·단축 펀딩 주기, 상장기간, 유니버스·배치 검증, 독립 API 라우팅.
- `npm run verify`: 기존 프로젝트 전체 회귀 검증.
- DOM 통합 확인: 시세→예비→정밀 순서, 결과 수, 필터·검색, 근거 펼침 보존, API 실패 표시. jsdom을 이용한 로컬 검사이며 실제 브라우저 레이아웃 확인은 아님.
- 원격 브라우저가 로컬 미리보기 접속을 차단했고, 로컬 Binance 실제 연결은 제한 시간 초과. 운영 환경 실데이터와 모바일 시각 검증은 배포 전 남은 항목.
- 뉴스·상폐·언락 일정, 현물 교차검증, 체결 슬리피지 실측, 수익성 백테스트는 미포함. 상장 26주 미만은 주봉 데이터 부족으로 진입 확인 불가.
- 기존 운영 사이트에 배포하지 않음. 운영 반영은 별도 승인 후 진행.
