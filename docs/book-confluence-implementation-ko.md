# 책 합성 실전 랩 — 구현 메모

## 목적

PR #79의 Forex Book p.201~350 엔진과 PR #78의 Simple Trading Book 엔진을 유지하면서, 새로 확보된 **기술적 차트 분석**과 **코린이 입문서**의 강점을 별도 근거 레이어로 추가한다.

핵심 원칙은 책 내용을 단독 매매 신호로 바꾸지 않고, 기존 SMC/ICT/Forex/Simple Trading 근거와 함께 **근거 완성도**로 합성하는 것이다. 이 점수는 승률이나 수익률이 아니다.

## 소스에서 직접 구현한 개념

### 기술적 차트 분석
- p.14: 5·20·60·120 이동평균 배열/밀집/확산 해석
- p.15~17: 가격과 거래량을 함께 해석, 상승 중 거래량 약화, 장대양봉 후 다음 음봉 거래량 비교
- p.104~106: 일목 시간론의 기본수치/대등수치와 변화일 개념
- p.108~109: 가격론 V/N/E/NT 계산치
  - V = B + (B - C)
  - N = C + (B - A)
  - E = B + (B - A)
  - NT = C + (C - A)
- p.110~112: 계산치는 가이드라인이며 시간 분석을 우선하고 다른 기법과 함께 사용
- p.114~121: 피보나치 되돌림/확장, 다른 기술적 요소와의 결합, 직접 신호로 단정하지 않음

### 코린이 입문서
- 기술적 분석은 미래를 맞히는 예언보다 가능한 시나리오를 만들고 대응하는 접근
- 캔들 패턴 하나만으로 방향을 단정하지 않고 시나리오 가중치로 사용
- 3회 이상 지지/저항이 확인된 추세선에 더 높은 신뢰를 부여
- 꼬리 돌파와 종가 돌파를 구분하고 종가 마감을 확인 기준으로 사용
- 여러 기술적 요소가 같은 가격/시간대에 겹치는 **Confluent Zone**
- 횡보/수렴에서 거래량·변동성 감소, 주요 레벨 이탈 뒤 추세 구간으로의 전환
- 여러 상승/하락 파동 시나리오를 동시에 두고 근거에 따라 가중치를 부여
- 피보나치 Projection은 A/B/C 세 변곡점을 활용하고 단독 신호가 아니라 보조 근거로 사용

## 자동화 근사

원문이 수치 임계값을 제시하지 않은 부분은 자동화가 가능하도록 보수적인 근사 규칙을 사용한다.

- 이평 밀집/확산: 현재 이평 이격과 5봉 전 이격 비교
- 거래량 강화/약화: 최근 5봉 평균과 이전 5봉 평균 비교
- 추세선: 최근 3개 이상의 피벗에 선형 적합 + ATR 허용오차
- 시장 국면: ATR·거래량·최근 20봉 고저 돌파를 조합한 수렴/추세/전환 근사
- Confluent Zone: ATR/가격 기반 허용범위 안에서 레벨 군집화
- 피벗 기반 일목 시간론: 최근 피벗 간 봉 수를 기본수치 범위와 비교

이 값들은 책의 원문 수식이나 저자가 제시한 승률이 아니다. UI에서도 **자동화 근사**와 **근거 완성도**로 표시한다.

## 기존 엔진과의 관계

```
OHLCV
  ↓
기존 Trend / SMC / ICT / Liquidity
  ↓
Simple Trading Book
  ↓
Forex Book
  ↓
기술적 차트 분석
  ├─ 이평 밀집도
  ├─ 거래량 구조
  ├─ 일목 시간·가격론
  └─ 피보나치 확장
  ↓
코린이 입문서
  ├─ 종가 확인
  ├─ 추세선 상태
  ├─ 시장 국면
  └─ Confluent Zone
  ↓
책 합성 시나리오
  ├─ 근거
  ├─ 반증/위험
  └─ 다음 확인 조건
```

책 합성 레이어는 기존 분석을 대체하지 않고, 기존 결과를 서로 교차검증하는 보조 Evidence Layer로 동작한다.
